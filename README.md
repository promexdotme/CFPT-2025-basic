## About the CFPT

The Consular Fellows Program Test is a competitive exam for the U.S. Department of State's Consular Fellows Program. The exam covers:
- **Section 1:** Comprehending Regulations
- **Section 2:** English Expression
- **Section 3:** Job Knowledge
- **Section 4:** Situational Judgment

Pass threshold: ≥70% on each section.
